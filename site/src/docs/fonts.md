# Fonts

Some themes use fonts that can't be bundled for copyright reasons. Until you add them, those themes fall back to a generic font. Get the font, then use *Import…* in the GUI, `f` in the TUI, or:

```sh
darwan font import <theme> <file>
```

In a source checkout, drop the file into the theme's `font/` folder instead.

| Terraria | Andy Bold | `Andy Bold.ttf` | Commercial (Monotype) | [MyFonts](https://www.myfonts.com/collections/andy-font-matteson-typographics/) |

`darwan doctor` lists every font that's still missing.
